# 利息の上限（risoku-jogen）

50万円を借りたら利息は何%まで？天引きされたら？返すのが遅れたら？お金を借りる場面を見て、利息制限法の決まりどおりの答え（上限の利率・超えた分・天引き・手数料・遅れたときの損害金）を選ぶ1日5問の学習ゲーム。正解したら「これは、どの決まり？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/risoku-jogen/>

- 答えは、e-Gov 法令検索の利息制限法（<https://laws.e-gov.go.jp/law/329AC0000000100>）第1〜7条の条文（2010年6月18日施行の版を、2026年11月17日に読みました）で確かめたことだけです。
- 人の名前・金額は作り話です。出資法の罰則・貸金業法（借りられる額の決まりなど）・払いすぎた利息を取り戻す手続きは、このゲームでは答えにしません。利息制限法の決まりだけです。一人ずつの事情の判断も答えにしません。
- このゲームは利息の上限のきほんを知る練習です。法律の助言ではありません。公式の情報の代わりではありません。自分の場合どうなるかは、消費生活センター（消費者ホットライン 188）や専門家に確かめてください。消費者ホットライン: <https://www.caa.go.jp/policies/policy/local_cooperation/local_consumer_administration/hotline/>
